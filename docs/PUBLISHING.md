# 공개 판단과 배포 절차

## 1. 공개해도 되는가 — 판단 기준

이 저장소는 **public** 이다. 올리는 순간 장면이 그대로 세상에 공개되고, 한 번 받아
간 사람의 사본은 회수할 수 없다. 그래서 "찍은 것"이 아니라 "보이는 것"을 기준으로
판단한다.

### 필수 (하나라도 걸리면 공개하지 않는다)

- [ ] 사람의 얼굴이 식별 가능하게 나오지 않는다
- [ ] 차량 번호판이 나오지 않는다
- [ ] 이름·전화번호·주소·사번이 적힌 것이 나오지 않는다
- [ ] 화면(모니터·키오스크)에 개인 정보가 뜨지 않는다
- [ ] 출입증·열쇠·비밀번호가 적힌 메모가 나오지 않는다
- [ ] 남의 집·사무실 내부가 아니다 (소유자의 허락이 없다면)

### 이번 프로젝트의 판단

> **공개 가능.** 화면에 나오는 것은 책상 위 손목시계와 재단 매트, 그리고 일부 키보드
> 자판뿐이다. 사람의 얼굴·차량 번호판·이름이 적힌 물건·화면에 뜬 개인 정보가 없고,
> 제3자의 사적 공간도 아니다. 시계는 상품이지 개인 식별 정보가 아니다.

이 한 줄이 README 에도 들어간다. **근거를 "왜"까지 적는 것이 요점이다.**
"괜찮을 것 같아서"는 근거가 아니다.

### 애매할 때

| 상황 | 판단 |
|---|---|
| 배경에 지나가는 행인 | 흐릿해도 얼굴이 보이면 재촬영 |
| 카페에서 찍은 테이블 | 다른 손님의 소지품이 잡히면 재촬영 |
| 도서관 서가 | 책 등록번호는 괜찮지만 대출 기록이 보이면 안 됨 |
| 사무실 | 모니터·화이트보드·서류를 먼저 치운다 |
| 공용 공간 | 촬영 금지 표시가 없는지 확인 |

**판단이 서지 않으면 공개하지 않는다.** 저장소를 지워도 이미 받아 간 사본은 남는다.

## 2. 배포 절차

```bash
# 1) 파일 확인 (100MiB 미만, 이름 정확)
ls -lh scene.sog index.html .nojekyll

# 2) 올리기
git add index.html scene.sog .nojekyll README.md docs shots
git commit -m "feat: 3D 뷰어 배포"
git push origin main

# 3) Pages 켜기 (처음 한 번)
gh api -X POST repos/eple-lab/3d-viewer/pages \
  -f source[branch]=main -f source[path]=/
```

Settings → Pages 에서 손으로 해도 같다. **Source: Deploy from a branch, main / (root).**

## 3. 배포 후 반드시 확인할 것

이 세 가지를 순서대로 한다. 하나라도 빠지면 "주소는 열리는데 화면이 까만" 상태가 된다.

### (1) 파일이 실제로 내려오는가

```
https://eple-lab.github.io/3d-viewer/scene.sog
```

브라우저 주소창에 그대로 붙여 넣어 **파일이 다운로드되거나 바이너리가 표시**되면 성공.
404 면 배포가 아니라 파일 위치 문제다.

```powershell
# 명령으로 확인
curl.exe -sI https://eple-lab.github.io/3d-viewer/scene.sog | Select-String "HTTP/|content-length"
```

`200` 과 `content-length` 가 0 이 아니어야 한다.

### (2) 페이지가 뜨는가

```
https://eple-lab.github.io/3d-viewer/
```

왼쪽 위에 단계 목록이 다섯 줄 나오고, 마지막까지 `OK` 로 바뀌어야 한다.
`X` 가 뜨면 그 줄의 안내를 읽는다.

### (3) 폰에서 열리는가

- 아이폰 Safari, 안드로이드 Chrome **양쪽**에서 확인
- Wi-Fi 를 끄고 셀룰러로도 한 번 (회사·학교 네트워크가 CDN 을 막는 경우가 있다)
- 세로로 들었을 때 패널이 화면을 덮지 않는지

## 4. 되돌리기

| 상황 | 조치 |
|---|---|
| 잘못된 장면을 올렸다 | `gh repo delete` 또는 Settings → Danger Zone → Delete. **이미 받아 간 사본은 회수 불가** |
| 파일만 잘못됐다 | 새 커밋으로 덮어쓴다. Pages 는 1분 안에 갱신된다 |
| 비공개로 돌리고 싶다 | Settings → General → Change visibility → Private. Pages 도 함께 꺼진다 |

## 5. 자주 막히는 곳

| 증상 | 원인 | 조치 |
|---|---|---|
| 404 (페이지) | Pages 소스가 `main / (root)` 가 아님 | Settings → Pages 확인 |
| 페이지는 뜨는데 파일 404 | 파일 이름 대소문자 불일치 (`Scene.sog`) | git 은 대소문자를 구분한다 |
| 파일이 100MiB 초과 | 알갱이 수 과다 | K 키우기 또는 점 감축 후 다시 |
| `.sog` 가 HTML 로 내려옴 | `.nojekyll` 누락 | 빈 파일 추가 |
| 폰에서만 안 됨 | CDN 차단 또는 구형 브라우저 | 최신 크롬/사파리 확인 |
| 화면이 까맣다 | `SparkRenderer` 누락 또는 파일 404 | 개발자도구 콘솔 확인 |
