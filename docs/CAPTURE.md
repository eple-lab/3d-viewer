# 촬영 조건과 이번 영상 판정

## 1. 무엇이 좋은 영상인가

복원 모델은 **사진 사이의 시차(parallax)** 로 거리를 잽니다. 같은 물체가 앞뒤 사진에서
얼마나 옆으로 밀려 보이는지가 거리의 근거입니다. 그래서 "얼마나 잘 보이는가"보다
**"카메라가 얼마나 옆으로 움직였는가"** 가 결과를 좌우합니다.

| 조건 | 기준 | 어기면 |
|---|---|---|
| 걸어 다니며 | 카메라 이동 ≥ 장면 대각선의 10% | 아치형 왜곡, 전체 붕괴 |
| 가로 | `width > height` | 천장·바닥이 화면을 먹어 정보 손실 |
| 15~20초 | 24장을 뽑기에 충분 | 길면 같은 장면 반복, 짧으면 시차 부족 |
| 흐리지 않게 | 장별 선명도가 중앙값의 절반 이상 | 번진 장이 정합을 끌고 감 |
| 노출 고정 | 자동 노출·자동 초점 끔 | 프레임마다 밝기가 달라 색이 얼룩 |
| 사람 없이 | 얼굴·번호판·개인 물건 제외 | 공개 불가 |

## 2. 촬영 절차 (30초)

```
1. 피사체 앞 1.5m, 가로로 든다. 자동 초점·자동 노출을 끈다(가능하면).
2. 3초 정지 — 시작 프레임이 흔들리지 않게.
3. 왼쪽으로 두 걸음, 오른쪽으로 네 걸음. 속도는 일정하게.
4. 끝에서 3초 정지.
5. 찍은 자리에서 바로 재생해 본다. 번진 장이 있으면 다시.
```

**제자리에서 몸만 돌면 안 됩니다.** 그것이 가장 흔한 실패이고, 영상만 봐서는
멀쩡해 보입니다. 판정은 6단계의 `퍼짐/대각선` 비율로 합니다.

## 3. 이번 영상 판정

| 항목 | 값 | 판정 |
|---|---|---|
| 파일 | `data/video/watch.mp4` (5.3MB) | — |
| 해상도 | 1920×1080 | 가로 ✓ |
| 길이 | 16.21초 | 15~20초 ✓ |
| 원본 fps | 27.20 (441프레임) | ✓ |
| 코덱 | HEVC | ✓ |
| 추출 | `fps = 24/16.21 = 1.4801` → 24장 | ✓ |
| 선명도 중앙값 | 8.34 | 기준선 |
| 선명도 최소 | 4.59 (15번째 장) | 중앙값의 55% — 기준(50%) 안쪽 |
| 번진 장 (중앙값 50% 미만) | 0장 | ✓ |

선명도는 회색조 480×270 에서 이웃 화소 차이의 평균이다. 값이 낮을수록 번졌다.
**절대값은 장면마다 다르므로 장면 안에서만 비교하십시오.**

### 피사체에 대한 판정

이 클립은 **책상 위 손목시계를 가까이에서 훑는 영상**입니다. 공간이 아니라 물체입니다.

| 기준 | 이 클립 | 비고 |
|---|---|---|
| 걸어 다니며 | ✗ (제자리에서 피사체를 훑음) | 카메라 자체는 움직였다. 다만 피사체가 화면을 가득 채워 **배경 시차가 적다** |
| 가로 | ✓ | |
| 15~20초 | ✓ | |
| 흐리지 않음 | △ | 12~16번째 장이 눈에 띄게 부드럽다. 빠르게 지나간 구간 |
| 공개 가능 | ✓ | 사람·얼굴·번호판·개인 서류 없음 |

**함의**: 물체 스캔으로는 잘 나올 가능성이 높다(피사체가 화면을 크게 차지하고,
질감이 많고, 회전하며 찍었으므로 시차가 생긴다). 다만 과제가 요구하는 "공간"의
정의에는 못 미친다. 판단은 `README.md` 의 공개 판단 절에 그대로 적는다.

## 4. 다시 찍어야 하는 신호

| 신호 | 뜻 | 조치 |
|---|---|---|
| 퍼짐/대각선 < 0.1 | 제자리 회전 | 재촬영 필수 |
| 아치형으로 휘어 보임 | 시차 부족 | 재촬영 |
| 한쪽 면이 통째로 검음 | 그 면을 안 찍음 | 반대편에서 한 번 더 |
| 같은 무늬가 두 번 겹침 | 정합 실패(반복 무늬) | 무늬 있는 물체를 하나 끼워 넣고 재촬영 |
| 거울·창문이 하얗게 튐 | 반사 | 각도를 틀어 재촬영 |
