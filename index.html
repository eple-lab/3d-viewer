화면이 까맣고 오류도 안 뜬다
알갱이는 다 올라갔는데 SparkRenderer 를 장면에 안 넣은 것입니다. Spark 는 자체 렌더러를 scene.add() 해야 그립니다. 빠뜨리면 조용히 아무것도 안 그리고 오류도 안 냅니다. 위 목록 둘째 줄을 보십시오.
장면이 거꾸로 서 있다
복원 모델은 Y 가 아래를 향하고 three.js 는 Y 가 위입니다. 노트북에서 y·z 부호를 뒤집지 않았다면 위 뒤집기 를 누르십시오.
알갱이 개수는 나오는데 화면이 비어 있다
알갱이 덩어리는 일반 메시가 아니라 Box3.setFromObject 가 빈 상자를 돌려줍니다. 카메라가 엉뚱한 곳을 보는 것입니다. 이 페이지는 Spark 의 getBoundingBox() 로 재고, 그것마저 실패하면 손으로 놓습니다.
파일을 못 받는다 (404)
file:// 로 열면 브라우저가 파일 읽기를 막습니다. 폴더에서 python -m http.server 8777 을 띄우고 http://localhost:8777 로 여십시오. 웹에 올렸다면 주소 뒤에 /scene.sog 를 붙여 파일이 실제로 내려오는지 먼저 확인하십시오.
Invalid file type
확장자와 Spark 안쪽 이름이 다릅니다. .sog 는 pcsogszip 입니다. sog 라고 적으면 걸립니다.
